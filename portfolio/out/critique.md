# 作品集 · 每页自评记录

> 每页至少两轮：出 PNG → 写下最弱的三处 → 改 → 再出 PNG，才推给用户（计划「审美要求与自我批评」）。

## P01 封面

**样机版**
- 第 1 轮：①字标「慢牛 Milo」压在 Logo 上（倾斜没绕基线）；②三台样机一样大、扇形排开，没有主次，右后那台被裁掉大半，看着乱；③背景荧光铺成一片发脏的橄榄绿，没有光源感。
- 第 2 轮改：字标绕基线倾斜；前台 today 放大到 510 宽、出血到底边，body 偏上、gains 偏下错开，压暗 42 % 推远；光收成主角卡身后一个亮核心。
  新问题：光被前台挡住又被压暗层盖掉，「背后有光」读不出来；页码撞上右侧样机。
- 第 3 轮改：后景与前台之间夹一层半透明荧光雾（前台像从光里走出来）；封面去掉页码。
  新问题：雾的颗粒在 1/4 分辨率上放大，成了电视雪花。
- 第 4 轮改：雾改半分辨率、细颗粒，范围收在前台上半身后面。✓
- 保留的取舍：标题句号「。」是唯一一个荧光字，与屏内「开始训练」按钮同色，两者一大一小、一字一图，不算抢焦点。三台样机倾斜 11°，与 Logo / 字标的倾斜同一个角度。

**实拍版（AIGC 3 号图）**
- 贴屏：绿幕凸包 → 四边各自拟合直线求虚角 → 透视贴 today 屏 → 只替换绿色像素，拇指留在屏前 → 去绿溢色；屏幕加 0.7 px 模糊和颗粒对齐照片的胶片感。
- 第 1 轮：左侧窗景太亮压不住字 → 横向 + 底部两道渐变压暗（SVG 渐变，Figma 里可调）。
- 保留的取舍：手机在照片里只有约 240 px 宽，屏内字看不清；封面靠氛围，样机版负责看清界面，两版分工。

## P09 容量页

- 素材：人体用同一页面 6 倍像素密度渲染（藏起胶囊列与页头只截舞台）；放大镜是按住不放时截的；M02 用冻结时钟逐帧（ready 后暂停全部动画、逐刻设 currentTime），并从 `::view-transition-group` 的计算样式读出浮层框每一刻的真实位置。
- 第 1 轮：①人体上的标注一行太长，钻到样机 A 底下，引线又长又乱；②M02 叠影把每一刻的框都画在最终浮层上，像一叠嵌套卡片，读不出在动；③MuscleWiki 署名压在页脚上，「过冲」标签挤在画布边缘。
- 第 2 轮改：标注改两行（名称 18/700 + 一句 14），统一收在人体右侧暗部；样机 B 换成形变中途 90 ms 的真实一帧——之前的轨迹画实线（起点胶囊荧光）、之后的画虚线、过冲那一圈荧光虚线；署名并进说明行；过冲标到时间刻度上。
- 第 3 轮改：虚线只留「过冲」与「终态」两圈（去掉 160 ms，太挤）；刻度文字不再互相压、不压页脚线。✓
- 保留的取舍：页头小号压在人体上方暗部，人体从左缘出血、占半页，是全页唯一主角；两台样机不倾斜，标注坐标要准。

## P21 成果一览

- 第 1 轮：①左侧渐隐不够，主张句压在「牛龄」样机上，大数字被「钱包」干扰；②上下渐隐太弱，出血边像硬切；③首页落在中下方被底边切掉一半——排位按旋转前坐标算，没算倾斜后的真实位置。
- 第 2 轮改：按旋转后的真实中心给每格打分（离可见区中心越近越显眼，竖向权重更大），容量 / 首页 / 记录 / 增量 / 进步曲线落在最清楚的位置；左侧渐隐加宽加深（压字区 97 %），上下渐隐 300 / 360。✓
- 第 3 轮改：左侧渐隐收窄到 860，不压首页那台的左边框。
- 保留的取舍：整组倾斜 11°，与封面、Logo 同一个角度，作品集首尾呼应；左侧页头与「15」之间大片留白不填。
