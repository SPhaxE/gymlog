# taste-skill（第三方，已安装）

来源：<https://github.com/Leonxlnx/taste-skill>，提交 `ce26fc2`（2026-10-06 安装），MIT 协议（见 `TASTE-SKILL-LICENSE`）。内容原样复制自该仓库的 `skills/`，未改动。

用法与边界：
- 它是**着陆页 / 作品集 / 重设计**方向的「反模板化」设计指南，不是手机 App 产品界面的规范；技术栈默认 Tailwind + Next，本项目不用。
- **冲突时以本项目 `docs/DESIGN.md` 为准**。例如它把「暖米白 / 骨白」列为高级消费品的禁用默认色，而骨白（`#E9E3D3`）是本项目已定的语义色；它建议的图标库、字体、框架都不适用。
- 对本项目最有用的：`stitch-skill`（给 Stitch 写 DESIGN.md，我们用 Stitch 出方案）、`imagegen-frontend-mobile`（出手机界面参考图的提示词）、`redesign-skill`（审查现有界面的「模板味」）、`taste-skill`（品味检查清单）。
- 新会话启动后这些技能才会出现在技能列表里。
