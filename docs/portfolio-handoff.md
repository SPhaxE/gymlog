## 0. 一页结论

- **项目**：慢牛 Milo——给刚过新手期的健身者的 Android 训练 App：根据恢复、训练量和近期表现，告诉你今天练什么、每组加多少（渐进超负荷 × 超量恢复）。Slogan「慢慢变牛。」
- **成品状态**：App 本体、规范、组件库、演示页都上线了。线上 <https://gymlog-taupe.vercel.app/demo>（电脑打开是左讲解右手机，手机打开直接进 App）；安卓 debug APK 由 CI 自动打包，提交在 `main` 的 `apk/` 目录。
- **作品集要讲的主线**：一个人 + AI，按「交互设计五层 → 低保真 → Stitch 视觉参考 → 高保真代码 → 用户逐项审查」的流程，把一个训练 App 从定义做到能装在手机上用；中间用 **Token 体系 + 门禁脚本** 保证几百次迭代不走样。浅色模式（2026-10-10）是对 Token 体系的一次验收：**组件一行不改，换一套语义色映射就整体换肤**。
- **用户定的硬要求**：
  1. 作品集里的界面**必须用真实的 iOS / 安卓页面样机**（真系统界面、真机框），不用自己画的手机框（2026-10-08 用户原话）；
  2. 要展示**过程**：旧默认和落选方案都留在方案台 `/preview`，不删（2026-10-07）；
  3. 视觉效果优先（「效果第一」「动效要非常有感觉」）——动效要录屏，静态图讲不清的不要硬截。

## 3. 浅色模式（作品集的第 7 段，也是 Token 验收）

**用户原话**（2026-10-10）：「进入作品集之前，先设计全局切换的浅色模式，最好能做到代码级别的一键切换，正好验证我们辛苦建立的设计 Token 是否有效。主题色还是荧光绿，但也要注意是否需要微调以更好搭配浅色模式。」

### 3.1 怎么做到「一键」

- 页面只用语义色 `--milo-color-*`。`tokens.css` 里 `:root` 是深色、`[data-theme='light']` 是浅色；切主题 = 改 `<html data-theme>`。
- **代码级一键**：`src/styles/theme.ts` 的 `DEFAULT_THEME`，改这一行全局默认就换了。
- 用户：「我的 → 外观 → 主题」（跟随系统 / 深色 / 浅色）；`/demo` 手机下面、`/playground` 左上角各有切换；地址栏 `?theme=` 临时指定。
- 首帧不闪（`index.html` 小脚本）、安卓状态栏图标跟着深浅变（Capacitor SystemBars）。
- Figma：插件给语义集合加 Light 模式（`design/figma-plugin/`，免费版 Figma 每个集合只能 1 个模式时会提示）。

### 3.2 验收结果（可以直接写进作品集）

- **组件代码零改动**就能切的：绝大多数页面（首页、增量、记录列表、我的、牛龄、消息、钱包、会员、商城、知识卡、结算、各种面板 / 对话框 / 键盘）。
- 改了的只有三类，正好说明 Token 哪里还不够：
  1. **荧光当字 / 线**：深色里荧光又当面又当线没问题；浅色里 #D4FF3A 当线几乎看不见 → 新增语义色 `accent/ink`（深一档的绿，纸白上 ≥ 4.5:1），32 处「荧光字 / 线」从 `accent/default` 换过去；
  2. **直接写了原色的组件**：Logo、道具图标、小牛装饰、选肌肉的人体 → 新增 `brand/mark`、`brand/mark-lit`、`picker/*`；
  3. **画布特效**：流体背景、颗粒光、粒子在 JS 里取色 → 改成从元素自己身上读 `fx/*` 语义色，切主题时重画。
- ~~刻意保留深色的「局部深色岛」~~ → **用户否决，做成真·全局浅色**（2026-10-10：「还没有实现全局浅色，人体容量、钢板等都需要实现全局浅色」「钢板透光等特效，浅色模式下就可以省去」）。作品集可以讲这段反转：第一版想「保住材质和舞台感」留了 5 个深色岛，用户一句话否掉；于是每个光效都重新想了一遍浅色下怎么成立——原则是「提亮 → 压暗」：
  - **容量人体**：4 个浅色方案 L1 深绿热 / L2 荧光热 / L3 银金属 / L4 墨印放方案台，用户选定 L2 的配色后觉得深色（描边、引线、胶囊边）还太多，又出 L2a–d 四个变体 + 6 种非深色描边（金属色带冷 = 纸白、热 = 深色，熔流和柔光描边从 screen 改 multiply）；
  - **钢板**：浅色拉丝铝板，不打灯，孔里露出平涂荧光底板；
  - **奖励弹窗**：纸白卡，闪白改荧光闪，发白改深绿细边 + 荧光外光晕；
  - **故事引导**：浅色水墨做过又封存——用户指出 App 默认深色、首次引导永远先看到深色，浅色下的引导动画没必要（产品判断：先砍掉没人会看到的工作）；故事固定深色，水墨代码留着
- **荧光的微调**：主题色不换；荧光面从 `lime-500 #D4FF3A` 深半档到 `lime-550 #C9F234`（纸白上不发虚）；荧光字 / 线用 `lime-750 #436A00`。中性实心（主按钮、分段选中、导航选中）从骨白换成墨黑 `ink-900`。
- **质量**：两套主题都跑对比度校验；门禁新增 `light` 一类（15 个页面 + 故事 8 幕 + 奖励弹窗 18 种 + /demo 外壳浅色下对比度、溢出、命中区，页里不许有局部深色岛，人体压暗混合、钢板孔里是荧光，外观切换持久化）；深色模式与改之前逐像素比对一致（冻结动画、固定随机种子和时钟，只剩计时器噪声）。
