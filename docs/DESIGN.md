## 0. 流程与门禁

```
tokens.json ─ build_tokens.py ─┬─> design/tokens/tokens.css   → CSS 变量与 .milo-text-* 文字样式
（只改这里）  （校验对比度）     ├─> src/styles/tokens.gen.ts  → JS 几何计算（放大镜、引线）用的数值
                                └─> design/figma-plugin/code.js → Figma 变量与样式
```

- 改值只改 `tokens.json`，再跑 `python3 scripts/build_tokens.py`。`contrast` 里列出的每一对颜色都要达标，否则不生成。
- `src/pages`、`src/components`、`src/playground`、`src/shell` 里**不许出现散落的颜色和尺寸**：不写 `#hex`、`rgb()`、`px`、`ms` 字面量（`npm run check:hardcoded`，CI 必过）。JS 里的尺寸和时长只从 `tokens.gen.ts` 的 `T` 取。唯一例外是 `@media` 断点（CSS 不允许变量），字面量必须等于某个 `size/bp-*`，检查脚本核对。
- 新组件的顺序：写进 `src/components` 并从 `index.ts` 导出 → 在 `catalog.tsx` 登记全部变体轴（`catalog.test` 会拦下漏登记的导出）→ 写进本文 §9 → 才能在页面里用。页面只从 `../components` 取组件，不自造样式。

## 1. 颜色：暖黑 + 骨白 + 荧光

只用语义变量（`--milo-color-*`），原始色（`--milo-prim-*`）不直接用。

| 角色 | 变量 | 用在 |
|---|---|---|
| 底与面 | `bg/base`、`bg/raised`、`bg/raised-2`、`bg/sheet`、`bg/scrim`、`line/*` | 页面底、卡片与胶囊、选中底、底部面板、遮罩、描边与分隔 |
| 文字 | `text/primary`、`text/secondary`、`text/disabled` | 正文；说明与单位；禁用与 0 组 |
| **骨白：选中 / 实心中性** | `control/selected`、`action/primary`、`nav/pill`、`data/gauge`（暗骨） | 分段选中项、导航选中项、中性主按钮（完成、确认）、增量尺的增量段；胶囊量尺填充 |
| **荧光：焦点 + 进度** | `accent/*`、`text/on-accent*`、`nav/progress` | 见下面的荧光规矩 |
| 数据 | `data/*` | 容量四档、人体图、引线、刻度 |
| 反馈 | `feedback/danger` | 只用于错误、清除数据、下降趋势 |

**荧光规矩（v2）**

1. 荧光只给两类东西：
   - **这一屏唯一的焦点或主操作**：首页的「开始训练」、放大镜中心的胶囊（含它的引线和人体上的描边）、详情面板里的当前时相段。
   - **进度**：导航外圈。
2. **每屏只能有一处荧光面积**。有荧光按钮时，主角卡不再用荧光，改用骨白点缀（例如增量尺）。
3. 导航选中项、分段控件选中项、中性按钮一律用骨白，不用荧光。
4. ~~容量四档不用荧光~~ → **2026-10-04 用户选定热成像（T4 荧光热）**：身体页的人体与胶囊量尺用荧光色带表示「热度」，这是规则 2 的唯一例外，只在身体页；色带明度单调上升，不靠色相也分得出冷热（§5）。
5. 光晕（`accent/glow`）只跟着那一处荧光走，每屏最多一处；首页「开始训练」的光晕边框（M06）就是这一处。
6. **氛围（A4）**：主角卡右上角荧光弥散 + 颗粒（只在光里）；Tab 根页最底层是流体噪点渐变（几团主题色光斑缓慢漂移，组件 `FluidBackdrop`）。训练中的页面不用。
   - **配重片光环**（2026-10-09 用户选定 P3，增量页头先用；阶段 5 推到全部同心纹，组件 `OrbitPlate`）：`ParticleField kind="orbit" inward`——粒子一圈圈向内收缩、收到光点；外面再压一层模糊、七成不透明（用户：「太实、抢焦点，加一层模糊」），只当氛围，不能比页头的数字醒目。落点：增量 / 曲线页头（光点在右上）、牛龄页小牛背后（光点在正中）、「我的」成长卡、会员卡 / 开通成功、商城推荐卡。静态的 CSS 同心纹不再用，只留在方案台 P0 对照。
   - **今天已练完**的那团荧光色块（走查 1 #18 收尾）换成和主角卡同材质的 `GrainGlow pulse calm`。
   - **主角卡**（2026-10-09 用户选定 H4，走查 1 #10）：`Card hero` 自带 `GrainGlow kind="pulse"`——还是右上角那团荧光往左下渐隐（A4 的形），但颗粒按设备像素画、**固定不动**，外面压一层很薄的模糊；光团按**心跳**泵：一大一小两下（扩张快、回落慢）再歇一拍，约 1.8 秒一拍。训练中、恢复日加 `calm`：约 2.6 秒一拍、亮度七成五（规则「训练中不用」对主角卡放宽：用户走查指的就是训练中的主角卡）。离开视野、切后台停；减少动态效果时定格在歇拍。H0 旧默认、H1–H3 落选的留在方案台 `#grain`。
7. **荧光分两级**（2026-10-09 用户选定增量页 J1，走查 1 #28「白块太多、没有主题色」）：
   - **面积**：实心荧光底（主操作按钮、「该加重」色带、商城丝带）——仍守规则 2，每屏一处（商城丝带是同一类状态的重复标记，算一处）。
   - **点缀**：荧光细线、描边小标、小曲线末点、上涨箭头和数字——不算面积，可以多处，但每一处都必须是「得到 / 变好」的意思（新纪录、在涨、进行中），不能拿来装饰。
   - 用点缀替代重复的骨白实心块：一屏里同一种标出现三次以上就不用实心块（例：增量页每行的 PR 由骨白实心改成荧光细线小标）。

## 1.5 主题：深色 / 浅色（2026-10-10）

用户：「进入作品集之前，先设计全局切换的浅色模式，最好能做到代码级别的一键切换，正好验证设计 Token 是否有效。主题色还是荧光绿，但要注意是否需要微调。」

- **怎么切**：页面只用语义色（`--milo-color-*`）。`tokens.css` 的 `:root` 是深色，`[data-theme='light']` 是浅色；切主题 = 改 `<html data-theme>`，组件一行不改。
  - **代码级一键**：`src/styles/theme.ts` 的 `DEFAULT_THEME`（`'dark' | 'light' | 'system'`），改这一行全局换默认主题。
  - **用户**：「我的 → 外观 → 主题」（跟随系统 / 深色 / 浅色），立即生效、记在这台手机上；地址栏 `?theme=light|dark` 只管这一次打开（演示、截图、门禁用）。
  - **/demo** 手机下面有「深色 / 浅色」切换（演示页外壳固定深色）；**/playground** 左上角切换，所有组件在两种主题下对照。
  - 首帧不闪：`index.html` 的小脚本在 JS 之前套上上次用的主题；安卓状态栏图标跟着变深 / 变浅（Capacitor SystemBars）。
- **源头**：`design/tokens/tokens.json` 每个语义色都有 `ref`（深色）和 `light`（浅色），`build_tokens.py` 生成两套变量，**两套都跑对比度校验**（同一张清单，`accent/default` 当图形的 3:1 只查深色——浅色里荧光当图形改用 `accent/ink`）。Figma 插件给语义集合加 Light 模式（免费版 Figma 每个集合只能 1 个模式时给提示）。
- **浅色色板**：
  - 底与面：纸白 `paper-0 #F2F0EA`（页面）、`paper-50`（卡片、面板）、`paper-100`（凹槽、分段底）、`paper-200 / 300`（线）——和骨白同一族的暖白，不是冷白。
  - 文字：主 `gray-0`（17.4:1）、次 `ink-600`（5.8:1）、禁用 `ink-500`。
  - **中性实心从骨白换成墨黑** `ink-900`：主按钮（完成、确认）、分段控件选中、导航选中滑块——深色里「浅色实心」的位置，浅色里是「深色实心」。
  - **荧光（主题色不变，微调两处）**：
    1. 荧光面（主操作按钮、该加重色带、商城丝带、焦点胶囊）用 `lime-550 #C9F234`，比 `lime-500` 深半档——纸白上 #D4FF3A 发虚、和底分不开；
    2. 新增 **`accent/ink`**：荧光当**字、线、小图形**（标签字、涨幅、描边、曲线点、导航进度环、要点短竖）时用它——深色里就是荧光本身，浅色里是深一档的绿 `lime-750 #4A7300`（纸白上 4.9:1）。规则：**荧光面用 `accent/default`，荧光字和线用 `accent/ink`**，两个都不许直接写原色。
  - 遮罩 `black-a40`、浮层阴影 `black-a16`（浅色里阴影轻得多）。
- **局部深色岛**（元素加 `data-theme="dark"`，里面的语义色就按深色解析）：
  - 容量页舞台是一块深色「热成像观察窗」（圆角、阴影）：人体的金属渐变、熔流、胶囊、引线都是为暗底调的，放在纸白上会糊成一团暗影；
  - 记录页钢板：钢板是实物，浅色下也是一块深色钢板（像真钢板放在纸上），上面的读数行跟页面；
  - 奖励弹窗：全 App 情绪最高的「舞台」，保持暗场 + 光；
  - 故事引导（`Screen theme="dark"`）：电影画面；
  - /demo 演示页外壳。
- **画布特效**（流体背景、颗粒光、粒子、钢板）从**元素自己身上**读颜色（局部主题也算数），语义色 `fx/glow-*`（主角卡颗粒光）、`fx/spark-0…3`（粒子四段）；浅色下粒子不用叠加混合（`lighter` 会冲成白），流体背景换一组纸白上看得见的光斑；切主题时重画（`useTheme`）。
- **品牌色**：`brand/mark`（标志主体：深色骨白、浅色墨黑）、`brand/mark-lit`（点亮的那一节：深色荧光、浅色同浅底 App 图标的 `lime-700`）；Logo、道具图标、小牛的装饰都用它。App 图标是成品图，深底版永远是骨白标志。
- **还直接用原色的地方**：只剩深色岛里（奖励弹窗、故事、钢板、人体）和成品图（App 图标）；新代码只用语义色。

## 2. 文字

| 字体 | 变量 | 用在 |
|---|---|---|
| Barlow Condensed（压缩粗体） | `font/number` | 所有关键数字：重量、组数、恢复 %、PR 数 |
| Noto Sans SC | `font/ui` | 中文和界面文字 |
| JetBrains Mono | `font/mono` | 计时与刻度读数（1:35），等宽防跳动 |

| 文字样式（`.milo-text-*`） | 字号 | 用在 |
|---|---|---|
| `Number/Hero` | 64 | 首页建议重量、详情面板的恢复 % |
| `Number/XL` / `L` / `M` | 40 / 30 / 22 | 面板里的组数；目标「3 × 6–8」；摘要读数、列表重量 |
| `Number/S` / `XS` | 15 / 12 | 胶囊里的组数；小读数 |
| `Title/L` / `Title/M` | 26 / 22 | 页面标题；面板标题、恢复日 |
| `Heading` | 17 | 卡片里的动作名、放大中心的肌头名 |
| `Body/Strong` / `Body` | 15 | 列表行名称；正文 |
| `Label` | 13 | 区块标题（接下来、恢复、近 7 天容量） |
| `Caption` | 12 | 说明、理由、单位、标签 |
| `Micro` | 11 | 图例、导航名称、刻度地标 |

- **字号下限 11**（`font-size/min`）。
- **数字 + 单位**：数字用 `Number/*`，单位（kg、组、%、小时）跟一个 `Caption`，颜色 `text/secondary`，中间留 `space/2xs`。统一用组件 `Num`。
- 放大镜的胶囊字号在 `Caption` 和 `Heading` 之间按权重插值；放大中心固定用 `Heading`。不要另造字号。

## 3. 间距、圆角

- 间距只用 `space/*`，全部是 4 的倍数：2 / 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48。
- 常用节奏：
  - 页头上边距 `space/l`，页头内块间 `space/s`，页头到内容 `space/m`；
  - 卡片内边距 `space/l`，卡片内块间 `space/xs`；
  - 内容区块之间 `space/m`；
  - 列表行最小高 `size/hit-min`（48），行间用刻度分隔线。
- 圆角：
  - `radius/pill`：胶囊、按钮、导航、分段控件；
  - `radius/l`：卡片、放大中心的胶囊；
  - `radius/m`：面板里的块、状态条；
  - `radius/s`：时相段底；
  - `radius/xs`：标签、刻度条；
  - `radius/xl`：底部面板顶角。

## 4. 版式

- **屏幕框**（组件 `Screen`）：
  - 背景全出血，宽屏时内容最宽 `size/content-max-w`（448）并居中；
  - **沉浸式全屏**（2026-10-08 走查 1）：底色、氛围层铺满整块屏幕，状态栏和手势条下面也是 App 的背景；只有内容（`Screen` 里的 frame、悬浮层里贴边的东西）避让系统栏。Android 由 Capacitor 注入 `--safe-area-inset-*`，`global.css` 收成 `--safe-top` / `--safe-bottom`；底部面板的遮罩和底色一直铺到手势条下面。
  - **全局不显示滚动条**：这是手机 App 不是网页（`global.css` 隐藏，安卓 WebView 原生滚动条在 `MainActivity` 里关掉），滚动照常。
- **出血规则**：一切内容都在左右 `size/gutter`（16）之内，人体图、胶囊、导航、按钮都不例外。只有背景色可以出血。
- **人体半身**（组件 `BodyFigure`，同 V1 `BodyProgressMap` 的做法）：
  - 人体放在左右各留页面边距的裁切框里，越界部分剪掉，不越过组件最外层；
  - 按包围盒从左裁：容量页裁到刚好露出完整腹肌（§5「人体位置」，`BodyFigure fit`），裁切量夹在 25%–70%（仍是半身）；其他地方（故事引导）沿用固定的 `ratio/figure-crop`（42%）；
  - 左缘再加 `ratio/figure-fade`（8%）宽的渐隐，让裁切读起来是有意的暗角，而不是一刀切；
  - 整体不透明度 `opacity/figure`，右侧再淡一些，让胶囊更清楚；
  - 胶囊列从内容区宽度的 `ratio/rail-start`（43%）开始，到内容区右缘结束。
- **底部留白**：
  - 有导航的页面，内容底部留 `nav-bar-h + nav-bottom + space/s`（CSS 变量 `--nav-clear`）；
  - 有固定主按钮时再加 `button-h + space/2xl`；
  - 主按钮浮在导航上方 `space/s` 处。
- **层级**（从下到上）：内容 → 人体 → 引线 → 胶囊 → 固定主按钮 → 导航 → 底部面板（含遮罩）。
- **触控**：目标不小于 `size/hit-min`（48）。视觉更小的件要把命中区外扩：分段控件高 32，用伪元素补到 48；静止胶囊的命中区按轨道均分。

## 5. 数据图形

- **容量 = 热成像**（2026-10-04 用户选定 T4 改荧光热，组件 `BodyFigure` / `Capsule` / `TierLegend`，代码 `thermal.ts`）：
  - 热度 t：没练 0.04；0 → 最低有效量 0.12 → 0.4；→ 适宜量 0.7；→ 最大可恢复量 0.88；超量到 1。
  - 色带（原色）：`gray-50` → `lime-900` → `lime-700` → `lime-500` → `lime-300`，明度单调上升。
  - 画法：每块肌肉一个径向渐变（中心热、边缘降到 55%）→ 小半径扩散裁回肌肉轮廓 + 大半径热晕 → SVG 渐变映射上色 → 横向扫描线与颗粒（热像仪质感）。人体仍是 MuscleWiki 真实路径。
  - 胶囊量尺用同一条色带；图例是一条色带，两道刻度标最低有效量与适宜量。
  - 旧的四档明暗 + 纹理（`data/tier-*`）只在 `/lab` 对照里保留。

- **胶囊**本身就是量尺：底色按「组数 ÷ 最大可恢复量」从左填充 `data/gauge`；0 组用斜纹并压暗文字。
- **放大镜焦点**（2026-10-04 用户第三轮反馈：无必要勿增实体）：不另开读数窗口，还是那颗胶囊。焦点胶囊实心荧光，**名称挪到最右**（手指按着的地方，放大前已看过名称），**左边三行**：组数 / 适宜量、恢复度 · 时相、还需几小时（`size/capsule-focus-h` 放得下三行），手指挡不到。
- **命中与滚动**：胶囊列的手势层只盖胶囊列的静止宽度 `[rail-start, 右缘]`；人体在它左边，**轻点肌肉 = 轻点那颗胶囊**，打开详情，两块命中区不重叠。手势层 `touch-action: pan-y`：竖向短滑滚动页面，按住 `motion/long-press` 不动才进放大镜，进入后拦下 touchmove 锁住滚动。胶囊列至少按 `size/capsule-rest-max-h` 排开，屏幕放不下就整页滚动。
- **人体位置**（2026-10-09 走查 1 #12，2026-10-10 用户两次修正）：**左缘贴页面边距、裁到刚好露出完整腹肌**——裁切线让正面腹肌左缘落在左缘渐隐的一半处（再往外露出腹斜肌，再往里腹肌被渐隐吃掉），正反面同一个比例；高度撑满舞台不变；屏幕窄、露出的宽度超过胶囊列起点时再多裁一点，手不越过胶囊列。
- **引线**（走查 1 #12）：**常态不画**。只有放大镜确认后（过了 `motion/long-press`）再等 `motion/fast`，才给**焦点胶囊**画一条折线：胶囊左缘中点水平出 `space/l` → 斜折到肌头锚点（荧光线 + 锚点小圆），沿线描出 `motion/base`；拖到别的胶囊立刻按新焦点重描；松手停 `motion/base` 再淡出 `motion/fast`；换人体卡途中不画。放大的那颗胶囊背后一层 `accent/glow` 泛光（它就是这屏唯一的荧光焦点）。
- **左右滑切正反**：在人体区（胶囊列左边）横向滑 ≥ `space/3xl` 且明显大于竖向：往左 = 背面、往右 = 正面，走换卡动画；滑过的这一下不算轻点。
- **正面 / 背面、男 / 女切换 = 抽卡**：当前人体像最上面一张卡被抽走（朝分段选择器的反方向滑出、转 8°、变淡，`motion/spring-ms`），下一张从后面略小处浮上来（`motion/spring`）；新的一张先量完锚点再浮上来，引线才对得上；两张卡只在人体自己那一层里叠（`isolation: isolate`），全程在引线和胶囊下面；减少动态效果时直接换。
- **刻度**只做分隔线和量尺，不做装饰：
  - 刻度间距 `size/tick-pitch`，小刻度高 `size/tick-minor`，大刻度 / 地标高 `size/tick-major`；
  - 分隔线（`Ticks`）向右渐隐。
- **地标尺**（`LandmarkRuler`）：已填段 `data/fill`，最低 / 适宜 / 上限三条地标 `data/tick`，位置 = 值 ÷（上限 × 1.1）。
- **增量尺**（`IncrementRuler`）：同一把刻度上标出上次和这次，中间那段（就是增量）用骨白高亮；减重时方向相反（−5 kg）。刻度步进 = 引擎的 `loadStep`（2.5 kg），两侧各留 4 步。
- **时相段**（`PhaseSegments`）：修复期 / 恢复中 / 黄金窗 / 已回落，当前段荧光（属于进度类用途）。
- **描边数字**（2026-10-09 用户，增量页 J1）：同一行左右两个大数字一虚一实时，「将来 / 目标」那个用描边无填充（`-webkit-text-stroke` 细线，颜色 `text/primary`，填充透明），「已经发生」的用实心——增量行「下次 27.5 kg × 6」描边、右边最新值实心。对比度门禁按描边色算。

## 7. 动效

参数都在 `motion/*`：
- 按下反馈 ≤ `motion/press`，缩放 `motion/press-scale`；
- 胶囊放大与位移 `motion/fast`；
- 底部面板滑入 `motion/base`；
- 单次转场 ≤ `motion/slow`；
- 列表入场总时长 ≤ `motion/list-max`。

放大镜的阈值：
- 按下的那一刻就开始**预放大**（放大程度 0.3，胶囊微微鼓起），按住 `motion/long-press` 确认后接着放满、锁住页面滚动——没有先等一段再动的空档（用户 2026-10-05）；轻点或开始滚动时预放大缩回；
- 进入前移动超过 `motion/drag-slop` 算滚动；
- 余弦衰减半径 `motion/magnifier-radius`（3 个胶囊）；
- 放大程度在 JS 里逐帧补间（约 `motion/fast` 到位），胶囊和引线同一帧算，跟手时不加 CSS 过渡；
- **引线**只给焦点胶囊画一条折线（§5，2026-10-09 走查 1 #12；以前是每颗一条直线，常态满屏是线）。

每个视效都要有「减少动画」降级（`references.md` §9.2）。

**性能**（2026-10-10 用户：小米 15 上动效到位但略卡；在不降视效的前提下优化，各 Tab 页静置从 35–44 帧、每 4 秒 58–100 个慢帧 → 稳定 60 帧、0–2 个慢帧）：
- **不在每帧重画的东西上做整屏模糊**：流体背景的 `space/2xl` 模糊在小画布里先做（按缩放比例换算），GPU 只剩一次放大；
- **能交给合成器的周期动画不进 JS**：主角卡心跳光 = 光画一次（泵到最大那一刻）+ 颗粒做成固定的 mask，心跳用 Web Animations 动 transform / opacity；
- **会动的滤镜层自成一层**（`will-change: transform`）：容量页熔流每步重算滤镜时不连带下面静止的金属层重新栅格化（栅格耗时约降到 1/8）；
- **粒子颜色查表**：每帧每粒子不再现拼颜色串；
- 试过但没用：流体背景每团光斑画一次、漂移交给合成器——主线程省了，但合成器每帧要叠四层大光斑，掉帧反而更多。训练页不放持续动画、光晕和噪点——例外：主角卡的颗粒光（§1 第 6 条，H4 `calm`：更慢、更淡）。

弹簧（2026-10-04，8motions 的形式，数值用 Token）：`motion/spring`（420 / 32，几乎不过冲）与 `motion/spring-soft`（252 / 17.6，约 12% 过冲）由 `build_tokens.py` 换算成 CSS `linear()`：`--milo-motion-ease-spring` / `--milo-motion-spring-ms`、`--milo-motion-ease-spring-soft` / `--milo-motion-spring-soft-ms`。

## 9. 组件与交互态（`src/components` → `/playground`）

`/playground` 是这一节的实物：82 个组件、625 个变体，每个变体是 `catalog.tsx` 里各轴取值的组合。下面的表只写用法；尺寸都在 Token 里，状态在 Playground 里看。

### 9.1 交互态（所有可点的件共用 `interactive.css`）

| 状态 | 代码里 | 样式 | Playground |
|---|---|---|---|
| 默认 | — | — | 默认 |
| 按下 | `:active` | 缩放 `motion/press-scale` + 内阴影 + 极淡的当前文字色叠色；松手按 `motion/spring` 回弹（M08） | `state="pressed"` → `data-pressed` |
| 聚焦 | `:focus-visible` | 骨白描边环 `stroke/focus`，外移 `space/2xs`（键盘、读屏、外接键盘时才出现） | `state="focused"` → `data-focus` |
| 禁用 | `disabled` / `aria-disabled` | 整体 `opacity/disabled`，不响应按下；要在旁边说明为什么不能点 | 禁用 |
| 加载 | `aria-busy` | 文字隐去、三点依次亮起（`motion/stagger`），宽度不变，不能重复点 | 加载中 |
| 错误 | `aria-invalid` | 描边与提示 `feedback/danger` + 警示图标（不只靠颜色），提示经 `aria-describedby` 读出 | 错误 |

- 触屏优先，**没有悬停态**。
- 命中区不小于 `size/hit-min`：视觉更小的件（分段、Chip、开关、图标按钮、周历）用 `::after` 把命中区外扩。
- 选中一律骨白（`control/selected`），**荧光只给每屏唯一的行动焦点和进度**（主按钮、焦点胶囊、时相当前段、导航外圈）。

### 9.2 数据态（每个页面都要覆盖，ia 各页「边界情况」）

| 数据态 | 组件 | 规则 | 示例 |
|---|---|---|---|
| 加载中 | `StateView kind="loading"` / `Skeleton` | 骨架与真实内容同尺寸，不跳动 | `/patterns/loading` |
| 空 | `StateView kind="empty"` | 说明为什么空 + 一个去下一步的主按钮 | `/patterns/empty`；身体页空态是一行小字 |
| 错误 | `StateView kind="error"` / `Banner tone="error"` / `Toast kind="error"` | 说清楚数据有没有丢，给「重试」；保存失败必须可见，不静默回退 | `/patterns/error` |
| 部分数据 | 页面就地处理 | 缺的行隐藏，不显示 0；只有 1 次记录写「基线」，少于 2 次不画线 | `TrendChart`、`Delta` |
| 分段加载（2026-10-08 走查 1） | `LoadMore` | 长列表一次渲染一段；滑到底自动加载下一段（底部 Logo 加载态 +「加载中」，停 `motion/slow` 再接上），全部加载完写「到底了」；不写「还有 N 周」按钮；一段就放得下的不出现 | 记录页按月分组（一段 6 个月）、牛龄页成长记录 |

### 9.3 悬浮层与返回键

- `Dialog`、`Toast` 渲染到壳的悬浮层宿主（`OverlayHost`），和 `Screen` 同一个框；Playground 的每块迷你屏幕各有自己的宿主。
- `Dialog`、`Sheet` 打开时焦点进入、Tab 在层内循环、Esc 关闭、关闭后焦点回到打开前的位置。
- Android 返回键（`src/shell/back.ts`，有单测）：先关最上面的悬浮层 → 非首页的 Tab 根页回首页 → 首页退出 App → 其余子页返回上一页。

### 9.6 交互硬规则（2026-10-06 演示验收后补，2026-10-08 走查 1 再补；`scripts/shoot_6a.py` 每一步都查，共 19 条）

每一页开工前按交互五层过一遍（战略 → 范围 → 结构 → 框架 → 表现），写在页面文件头注释里（例：`src/pages/TrainingView.tsx`）。下面是表现层落地时不许破的规则：

1. **命中区 ≥ 48 × 48**（`size/hit-min`）。视觉可以小（小按钮 44、分段 32、开关 28），命中区靠 `::after` 外扩或内边距补够；相邻控件的命中区不重叠。门禁：`scripts/lib/hit_audit.js` 从每个看得见、能点的元素中心往四个方向各 23 px 取点，必须落回它自己（被浮层盖住的不算）。
2. **主操作一屏一个、放在拇指区**（底部、导航上方）。不重复：同一件事不在卡里和底部各放一个按钮。
3. **不给死路**：主按钮不做「不可用」状态，缺什么就把按钮变成去补什么（「填重量 · 第 N 组」直接拉出键盘面板）。
4. **提示不位移**：输入的提示 / 报错行永远占位（空也占一行），出现时不挤动控件；组行里的提示是第二行，不参与第一行（序号 · 输入 · 按钮）的对齐。
5. **滚动容器里的网格**：`overflow: auto` 的 grid 必须写 `grid-auto-rows: max-content`，否则内容超过一屏时行高被压到 min-height、内容溢出重叠（2026-10-06 真机）。门禁「被压扁的块」会查。
6. **键盘按需出现**：自带数字键盘只在改数时从底部拉出（`Sheet` + `SetEditor`），平时不占屏幕。
7. **临时面板点别处就收**：放大镜、肌头详情这类展开态，点面板以外任何地方缩回，不挡后面的内容。
8. **转场不吞点击**：`::view-transition { pointer-events: none }`，转场进行中的点击落到底下的新页面。
9. **浮层下面垫渐隐**：底部固定的按钮 / 导航后面垫一层渐隐底色（`.scrim`），滚上来的内容在那里淡出，不和按钮抢。
10. **同一个东西屏上只出现一次**：休息计时在首页是主按钮旁的胶囊、在别的 Tab 是导航滑块，切换时是同一个元素飞过去（不是两个计时器同时在）。
11. **同一个数只有一个口径**：例如新纪录的增幅一律按「之前最好」算（结算页与奖励弹窗一致），逐动作表才是与上次比。
12. **对比度**（2026-10-06 用户）：文字对它实际的底色正文 ≥ 4.5、大字（≥ 24，或 ≥ 18.66 且加粗）≥ 3。门禁 `CONTRAST` 在 8 个页面逐个文字算（叠加半透明底色、乘上祖先透明度）；画在 SVG / 画布里的字（钢板月份、人体）靠截图核对——钢板月份是骨白 80% 的钢印字（约 7:1），不再用暗字压在灰钢上；0 组胶囊的字用次要色。
13. **标题位置稳定 + 回到顶端**（2026-10-06 用户）：Tab 根页标题上方不放东西、标题行固定 48 高，五个 Tab 的大标题 y 相同；不出现下滑小页头；长页滚过一屏右下出现「回到顶端」。**页头随内容滚走，训练中也是**（2026-10-08 走查 1）：固定在屏上的只有导航和拇指区的主按钮（以及计时胶囊），页头不贴顶。
14. **可撤销的走底部面板、不可撤销的走居中对话框**（2026-10-07，6e）：暂停训练、换一个、找动作都是底部面板（按钮在拇指区，点面板外 = 取消）；删除训练、清除数据、结束时还有没打的组是居中对话框。
15. **不该滚的不滚**（2026-10-08 走查 1）：内容不足一屏，滚动区就不能滚——不为了贴顶或动画把滚动区撑高（不写 `min-height: 100%`）；底部面板放得下（≤ 屏高 92%）就按内容高打开、只有一档、面板里不出滚动（键盘、确认、暂停这类定高内容）。门禁：增量页分组全收起时滚动区不能滚、改数键盘面板 `scrollHeight = clientHeight`。
16. **一行只放一件事，标题不意外折行**（2026-10-08 走查 1）：卡头 / 面板标题里，长名称（动作名）单独占一行，次要信息（第几组、之前最好、标签）放说明行或固定的右侧列，不和长名称挤在一行里折行；多行标题两行等长（`text-wrap: balance`），正文末行不留孤字（`text-wrap: pretty`），两件都在 `global.css` 全局生效；左右两列的读数基线对齐。
17. **App 里不出现「演示」**（2026-10-08 走查 1）：不放「演示模式」横幅、页脚、按钮括号；功能名用「示例数据」。演示说明只在 `/demo` 的讲解栏。门禁：每一步页面文字里都不能有「演示」。
18. **状态以真值为准，同一个判断处处一致**（2026-10-08 走查 1）：例如休息「在走」只看剩余时间 > 0——首页计时胶囊、导航滑块、要领页那一行用同一个判断，休息结束就不再写「还在走」。
19. **每个出现都有退场**（2026-10-09 走查 1 #02）：页面、面板、对话框、轻提示进来有动画，走也要有——不能「啪」一下没了；退场比进场快、用加速曲线（`motion/ease-accelerate`），见 §7 转场表。
