## 2. 同源归组与统一改法

### A. 转场与动效体系（01 02 06 08 25 26）
- **Tab 之间横滑**：只在点导航时。按导航顺序定方向（往右的 Tab 从右边滑进来），旧页同向滑出并压暗；时长 `motion/slow`（350 ms）+ 减速曲线，新页面在滑动期间完成首帧，重页面（容量页人体）借这段时间加载。休息计时飞进导航滑块的交接保留，和横滑合成一次转场。
- **子页推入 / 推出**：从右边推入、返回时推回去（不是列表行进来的子页，例如「我的」→ 牛龄、钱包）。
- **列表 → 详情一律共享元素**：首页处方行 / 主角卡 → 动作要领（名称飞成标题、卡片窗口展开）；商品卡 → 商品详情（商品图飞成大图、名称飞成标题）；记录、增量已有 M09，保留。
- **曲线钻入对位**：小曲线的点映射到大曲线最后 8 次的位置，转场时小曲线贴到大曲线重合的那一段，转场结束后更早的部分从右往左画出来。
- **面板、对话框、轻提示都有退场**：关闭先播退场（面板下滑、对话框缩小淡出、提示下滑），播完再卸载。
- **出现式图标描线**：跟着状态变化新出现的图标挂载时描一遍（今天已练完的勾、休息「好了」、轻提示、空态 / 错误态、横幅、新纪录标）；列表里随页面一起出现的不描。描线顺序改成「从下到上」优先于「从左到右」。

### B. 滚动与全屏（03 13 19 20）
- **沉浸式全屏**：底色、氛围层铺满到状态栏和手势条下面，只有内容避让安全区；全局不显示滚动条（CSS + 安卓 WebView 原生滚动条关掉）。
- **不该滚的不滚**：内容不足一屏不能滚；不为贴顶或动画把滚动区撑高；定高内容的面板（键盘、确认）按内容高度打开、不出滚动。
- **页头随内容滚走（训练中也是）**：固定的只有导航和拇指区主按钮。

### C. 主题色流体粒子（10 18，并影响 09 的光源）
- 一种材质、一个组件：低分辨率画布上的主题色粒子按流场缓慢流动，颜色是荧光 → 暗绿的渐变，叠颗粒；替换所有「荧光点缀色块」（主角卡右上角、今天已练完卡、奖励卡、结算新纪录卡的光）和「配重片同心环纹」（粒子沿同心环轨道流动），6 处同心环 + 4 处色块一起换。
- 先上 `/preview` 方案台出 3 种（漂浮光尘 / 流场丝带 / 环轨粒子）并排实时渲染，用户选定后全局替换；画布离屏暂停、减少动态效果时定格。
- 规则「训练中不用光晕和持续动画」要改：用户这次指的就是训练中的主角卡。默认：训练中也用，但更慢、更淡。

### D. App 里不出现「演示」（07）
- 删掉所有演示说明横幅、页脚、括号；功能名改「示例数据」；「我的 → 数据」里的会员开关改叫「会员状态」，说明写「打开 = 年度会员，关掉 = 免费」。演示讲解只留在 `/demo` 桌面讲解栏。
- 门禁：App 每一步页面文字里不能有「演示」。

### E. 商城（08）
- 「补给」→「补剂」（品类、占位图注释、知识卡）。
- 状态角标重做：每种状态有自己的形状和图形（不只是字），一眼区分；方案台出 2–3 种。
- 商品卡 → 详情走共享元素（见 A）。

### F. 记录页（09 14 15 17）
- 钢板改主题黑 + 背后要有光源本体（光从板后透过孔、光源位置固定在屏幕上，和光束角度一致）；休息日 = 白色手绘圆圈（4 种手绘笔触轮换，差别很小），可以选中，读数写「休息日」。方案台出 2 种光源做法。
- 页面太长：线框出 3 种收起方式（本周展开、更早按周折叠成一行 / 按月折叠 / 只留日历、列表在下面分段）。
- **加载更多统一**：列表滑到底自动加载下一段（底部 Logo 条一根根长出来的加载态），全部加载完写「到底了」；不再写「还有 N 周」按钮。记录页、牛龄成长记录两处。

### G. 容量页（12 29）
- 29：胶囊点开 = **M02 流体胶囊形变**——胶囊原地膨胀成一块浮在页面上的面板（尺寸与圆角一起按软弹簧长开），不是从底部升起的抽屉；点面板外或返回，缩回那颗胶囊。
- 人体右移到手刚碰到胶囊列；常态不画引线；长按放大时只给焦点胶囊画一条折线（胶囊左缘水平出、斜折到肌头锚点），出现延迟约 `motion/long-press` + `motion/fast`、消失延迟 `motion/base`；放大胶囊背后加泛光；人体区左右滑切正反（往左 = 背面，往右 = 正面，沿用抽卡动画）。

### H. 文字排版（19 23 24）
- **标题行不意外换行**：一行只放一件事，长名称独占一行，次要信息（组数、之前最好）挪到下一行或右侧固定列；面板标题用动作名，「第 N 组」放说明行。
- **多行标题平衡、正文不留孤字**：标题 `text-wrap: balance`、正文 `text-wrap: pretty`（全局默认）。
- **左右两列读数基线对齐**。
- 奖励弹窗按这套重排（阶段 4 出图给用户看）。

### I. 休息计时（21 22 27）
- 只保留小胶囊：不可展开，± 15 / 跳过一起去掉（打卡下一组就是结束休息）；休息结束胶囊显示「好了」并描一遍勾，打下一组时消失。
- 「在走」一律以剩余时间 > 0 为准：首页胶囊、导航滑块、要领页那一行用同一个判断，要领页休息结束就收起那一行。

### J. 色彩配比与主题色点缀（28，和 C 一起定）
- 现在的问题不在某一页：骨白承担了「选中、实心中性、PR 标、曲线、大数字」太多角色，荧光又被「每屏一处」整个禁掉，结果列表页一屏全是白块。
- 改法方向：骨白只留给选中和真正的主数字；重复出现的标记（PR、涨跌、曲线末点）不用实心白块，改成线 / 点 / 小图形；**荧光分两级**——荧光面积（主按钮、新纪录卡）每屏仍只一处，荧光点缀（PR 小标、曲线末点、上涨箭头这类点 / 线级）可以多处。
- 方案台出 3 种增量页配色（同一份数据并排），选定后改 DESIGN §1 荧光规矩，再全局扫一遍白块多的页（增量、记录、牛龄、我的、消息、结算逐个动作）。

## 3. 写进规范的新规则（`docs/DESIGN.md`）

1. §4 **沉浸式全屏**：背景铺满系统栏，内容避让安全区；全局不显示滚动条。
2. §9.6 **不该滚的不滚**（门禁查：内容不足一屏时滚动区 `scrollHeight ≤ clientHeight`；键盘面板不出滚动）。
3. §9.6 第 13 条补：**页头随内容滚走，训练中也是**。
4. §9.6 **标题行不意外换行 + 多行标题平衡 + 正文不留孤字 + 两列读数基线对齐**。
5. §9.6 **每个出现都有退场**（面板、对话框、轻提示、页面）。
6. §9.6 **App 里不出现「演示」**（门禁查每一步页面文字）。
7. §9.2 **分段加载统一**：到底自动加载 + 加载态 + 「到底了」。
8. §7 **转场表**：Tab 横滑 / 子页推入推出 / 列表 → 详情共享元素 / 面板与对话框进退场，各自的时长和曲线。
9. §6 **描线顺序**：从下到上优先于从左到右；§7 **出现式图标挂载时描线**。
- 随方案改的：§1 荧光规矩（点缀 → 流体粒子，训练中也用）、§5 引线（常态无、长按折线）、§9.7 M02 落点（休息胶囊不再展开）。
