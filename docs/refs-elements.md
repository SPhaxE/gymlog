## 3. 你点名要预览的两项

### A · 噪点渐变氛围（ref4、ref5、iconref2）

| 编号 | 做法 | 建议 |
|---|---|---|
| A0 | 现行：纯暖黑，没有颗粒 | — |
| A1 | 左上角一团荧光弥散光，颗粒只铺在光里（ref4 左屏） | 可选：Tab 根页的氛围底，训练中不用 |
| A2 | 右上荧光、左下骨白两团极淡的光 + 颗粒（ref5） | 可选：比 A1 更柔，适合身体页（右上的光正好落在胶囊列后面） |
| A3 | 底边升起的暖光（iconref2 的底部橙光，换成骨白偏荧光） | 不建议：光正好压在「开始训练」和导航后面，抢主按钮 |
| **A4** | 页面纯黑，**只有主角卡**带荧光噪点渐变（ref5「Hello, Peter」） | **推荐**：符合「每屏一处发光」，噪点只在大面积主角卡上 |

技术上：
- 颗粒是 canvas 生成一次的灰度贴图，平铺后用 overlay 叠加，不用全屏 `feTurbulence`（手机上太贵）；
- 颗粒只出现在有光的区域，暗处保持干净；
- 采纳后会补 Token：氛围光的不透明度、颗粒贴图尺寸。

### T · 热成像肌群容量

- **热度怎么算**：近 7 天组数对照三条地标。没练 → 最低有效量 → 适宜量 → 最大可恢复量 → 超量，明度单调上升，所以不靠色相也分得出冷热，满足「不只靠颜色」。
- **怎么画**：
  - 每块肌肉一个径向渐变，中心热、边缘凉；
  - 用 SVG 扩散出热晕，再按主题色板做渐变映射；
  - 胶囊量尺同步用同一条色带。
- **人体素材**：仍是 MuscleWiki 真实路径，只换上色方式。

| 编号 | 色板 · 质感 | 建议 |
|---|---|---|
| T0 | 现行四档（明暗 + 纹理） | — |
| T1 | 荧光热 · 辉光：暗 → 橄榄 → 黄绿 → 荧光 → 浅荧光 | 热成像感最强。但荧光会铺满半个人体，违反「每屏一处荧光」，胶囊焦点的荧光也会被淹没 |
| **T2** | 骨白热 · 辉光：暗 → 暗骨 → 骨白，**只有超过上限的热点才变荧光** | **推荐**：守住荧光规则，荧光从装饰变成「过量警报」，含义更强 |
| T3 | 荧光热 · 等温带：扩散后量化成 5 条带，像热像仪伪彩 | 可选：最「仪器」，但块面边缘偏硬 |
| T4 | 骨白热 · 扫描线：辉光 + 横向扫描线 + 颗粒 | 可选：最像热像仪画面，扫描线让小肌头的读数略糊 |

注意：演示数据里没有超过上限的肌头，所以 T2 的荧光热点在截图里看不到，最热的一端看图下方的色条。采纳后我会在演示场景里补一个「某肌头超量」的状态。

## 4. 8motions.md 的八种动效

数值不照搬：时长和弹簧都换成 Token（`motion/*`、`motion/spring` 换算成 CSS `linear()` 弹簧曲线），并且都要有「减少动态效果」降级。

| 编号 | 动效 | 用在 Milo | 预览 | 建议 |
|---|---|---|---|---|
| M01 | 3D 倾斜光影：跟手 ±5° + 高光，松手弹簧回正 | 首页主角卡 | /lab M01 | 不建议：主角卡没有「按住」这个任务，倾斜只是装饰；在可滚动页面上还会和滚动抢手势 |
| **M02** | 流体胶囊形变：小胶囊原地长成面板 | P03 的组间休息：底部「休息 1:35」小胶囊 ↔ 展开的休息面板（±15、跳过） | /lab M02 | **推荐**：和导航小胶囊同源，休息从「一条横幅」变成可收可展的胶囊 |
| **M03** | 共享元素展开：列表项原地长成详情，返回缩回 | 处方行 → 动作要领；记录行 → 训练详情；胶囊 → 肌头详情 | /lab M03 | **推荐**：上下文不断，最适合「从列表看一个」的结构 |
| **M04** | 磁吸游标 + 滚动码表 | P10 进步曲线（拖动吸到最近一次）；结算页总负荷 | /lab M04 | **推荐**：和 ref2 / ref4 / ref5 的游标一起，P10 的核心交互 |
| **M05** | 阻尼底部面板：两档吸附、拉过头有阻尼、按速度判档、下甩关闭 | 肌头详情面板、减量面板 | /lab M05 | **推荐**：替换现在只能点关闭的面板 |
| M06 | 弥散光晕边框：细圆锥渐变描边慢转 + 呼吸光晕 | 首页「开始训练」 | /lab M06 | 可选、只限一处：持续动画在训练页禁止；首页可以「进入页面时转一圈后停住」 |
| **M07** | 弹簧交错流：列表依次弹入 | 首页处方列表、增量列表的首次入场 | /lab M07 | **推荐**：总时长不超过 `motion/list-max` |
| **M08** | 微缩 + 内阴影 + 松手过冲 | 所有按钮的按下态 | /lab M08 | **推荐**：替换现在的「缩放 + 叠色」，松手按弹簧回到 1，自带一点过冲 |
