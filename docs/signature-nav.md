> 图像参考：一条磨砂玻璃的长胶囊导航，选中项底下有一块更亮的圆角胶囊。**图像只是形式参考**，不照搬配色、图标和材质。

## 1. 用户原话（原样保留）

> 导航栏还是传统大小胶囊滑动设计，但是大胶囊外圈描边显示当日训练进度，小胶囊不管选中哪一项都有描边显示组件休息时间，且这项功能进设置里可个性化自定。

## 2. 对应关系（用户 2026-10-03 确认）

| 元素 | 是什么 | 描边显示什么 |
|---|---|---|
| **大胶囊** | 整条底部导航的外轮廓（参考图里最外面那条长胶囊） | **今日训练进度**：外圈描边沿轮廓走一圈，走完 = 今天计划的组都做完了 |
| **小胶囊** | 选中项的滑块（参考图里「首页」底下那块亮的圆角块），切换 Tab 时滑动到新的项 | **组间休息倒计时**：描边按剩余比例收缩。因为小胶囊永远跟着选中项，所以**不管用户停在哪个 Tab，休息计时都看得到** |

> 如果用户指的是别的对应关系（例如「选中项是大胶囊、其余是小胶囊」），以用户为准，下面的待决事项照样适用，只是元素换个名字。

## 3. 为什么值得做

- 把产品最核心的两个「现在」（今天练到哪、还要歇多久）放进用户每个 Tab 页都会看到的地方，对应品牌关键词「透明」。
- 休息计时现在只在 P03 的悬浮条里；用户一旦去看 P04 要领或离开 P03，就只剩 P04 顶部一条文字。导航上的环让休息计时「跟得住人」。
- 导航本身就是品牌记忆点，和 P06 的放大镜胶囊轨道是同一个造型语言（胶囊）。

## 4. 待决事项（按阶段）

### 4.1 数据口径（阶段 3 前定，写进 ia）

| 问题 | 倾向 | 理由 / 影响 |
|---|---|---|
| 今日进度的分子分母 | 已完成工作组数 ÷ 今日处方计划组数；热身组不计 | 与 P01 / P03 现有的「N / M 组」同一个函数，不另写一套 |
| 没在训练时环显示什么 | 今天还没开始：空环（只剩轨道）；今天已练完：满环；恢复日 / 动作池不足：不画环（没有分母） | 「今天已练完」状态已在 §1.2 有定义 |
| 减量周 | 分母用减量后的组数 | 否则减量周永远走不满 |
| 用户加组超过计划 | 环封顶满环，不超过 100% | 超出的组在 P03 里已能看到 |
| 删组 / 改组 | 环实时回退 | 与 §1.5「改动立即反映统计」一致 |
| 休息描边的总长 | 本次休息的总秒数（含 ±15 秒调整后的新总长） | 调整时描边不能倒跳，要平滑过渡到新比例 |
| 休息结束 | 描边走空后给一个明确的结束态（形状变化，不只靠颜色），并随 P03 的结束提示一起消失 | §1.6 已有「结束时有提示」 |
| 数据源 | 休息仍用「结束时间戳」计算（§1.6）；环只是它的另一个显示 | 切后台 / 杀进程后回来依然正确 |

### 4.2 与现有规格的冲突点（阶段 3 已回答，见 `references.md` §9.4，结论写进 `ia.md` §1.6 / §1.12）

1. **P03 没有 Tab**（沉浸式记录，§6）。环只会出现在有 Tab 的页面（P01 / P06–P09 / P11）。休息中用户在 P03 时看悬浮条，离开 P03 后看导航上的小胶囊环——**P03 要不要也放一条精简导航？** 倾向「不放」，保持记录页干净；如果放，§6 的导航元素列要改。
2. **P04 要领页也没有 Tab**，目前顶部有一条「组间休息还在走：1:35」的文字。保留还是改成别的？
3. 休息计时现在有两处显示（P03 悬浮条、导航环）：P03 悬浮条为主，导航环是离开 P03 之后的延续，二者数据同源，不会不一致。
4. 浮层（底部面板）打开时，导航被遮住，环就看不到了——可接受，面板关掉即恢复。

### 4.3 设置（P11 新增一个分组，选项阶段 3 评审后定）

初版建议只放最少的几项，不要做成调色板：

- 显示今日进度环（默认开）
- 显示休息倒计时描边（默认开）
- 休息结束提示方式（默认：描边结束态 + 振动；可选：仅描边）

存储字段（阶段 5）：`settings.navRing = { progress: boolean, rest: boolean, restAlert: 'haptic' | 'visual' }`，默认值如上。改设置立即生效，不需要重启；保存失败要可见（沿用 §1.11 的规则）。

### 4.4 视觉与可访问性（阶段 3 / 4）

- **两层描边要能一眼区分**：外圈（进度）和内圈（休息）同时出现时，不能只靠色相。阶段 3 定稿：**外圈实线；小胶囊虚线 + 端点圆点**；小胶囊描边与胶囊本体之间留一道深色缝（B 方向白描边贴荧光胶囊时对比只有 1.03:1）。见 `references.md` §9.6、§12.4。
- 非文本对比度 ≥ 3:1（WCAG 1.4.11）；初版只做深色（brief v1.1.2），只验深色一套；磨砂玻璃背景上尤其要验。阶段 3 方向稿的实测见 `references.md` §9.6。
- TalkBack：整条导航的 contentDescription 写成「今日训练 8 / 14 组；休息剩余 1:35」，**不每秒播报**，只在整分钟或状态变化时更新。
- 系统「减少动画」：不做连续过渡，休息描边按整秒阶梯更新，小胶囊切换时直接到位。
- 性能：休息描边每秒更新一次，只在页面可见时运行；用 `stroke-dashoffset` 而不是重排布局；后台不刷新，回前台按时间戳重算。
- 与 `docs/references.md` 的视效关系：小胶囊的滑动 ≈ **02 Fluid Morph**（形变连续）；按下反馈 = **08 Press Scale**；若进度环加光晕，要和 **06 Conic Glow** 一起算「每页最多一处核心发光」的预算。

### 4.5 实现（阶段 5）

- 描边进度：SVG 圆角矩形路径，`pathLength="1"` + `stroke-dasharray` / `dashoffset`；大胶囊和小胶囊各一条路径；小胶囊随选中项滑动时，描边是它的一部分，一起移动。
- 组件名（与 Figma 同名）：`NavPill`；variants：无环 / 仅进度 / 仅休息 / 两者同时；props：`progress`（0–1，可为空）、`rest`（0–1，可为空）、`selected`。
- 组件预览页要覆盖：4 个 variant × 5 个 Tab × 减少动画（初版只有深色）。
- **v1.3（2026-10-03）**：导航由 3 项改为 5 项（首页 · 身体 · 增量 · 记录 · 我的，`ia.md` §3）。未选中项只显示图标，选中项展开为「图标 + 名称（+ 休息剩余）」；大 / 小胶囊的含义与线型不变。阶段 4 做的 3 项版 `NavPill`（30 个变体）作废，随新标杆页重做。
