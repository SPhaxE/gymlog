# 动作素材审计

> 日期：2026-10-03 · 审计对象：用户提供的 `gymlog_app_videos_bundle.zip`（V1 的 App 视频归档，MuscleWiki 来源）与 V1 动作库 `exercises.json`
> 目的：确认归档能撑起自适应引擎，并定出 MVP 的动作池。

## 2. 引擎的候选池

按引擎 `strictPool` 的规则筛选（器械在默认六类内、不在 `DENY_PATTERNS` 里、非等长保持、有主练肌头），并要求男、女的正面和侧面四段视频**全部存在**：

| 步骤 | 动作数 |
|---|---|
| V1 动作库 | 1,461 |
| 有视频字段（MuscleWiki 来源） | 1,408 |
| 去掉体能 / 爆发 / 等长等不适合增肌的动作（177）、扩展器械（308） | 约 920 |
| 四段视频齐全 | **920** |

结论：归档足够，不缺视频。

## 3. MVP 动作池（154 个）

**为什么不是全部 920 个**：引擎按「标准器械、经典动作」优先选，用不到大部分冷门变体；全量打包会让 APK 多出约 100 MB。

**怎么挑的**：
1. 先去掉冷门变体（暂停、站立绑带、悬挂、单臂单腿等）。
2. 每个肌头取 4 个复合动作 + 4 个孤立动作（不够就取全部），按引擎自己的排序（器械常见度、经典动作、名字简短）。
3. 人工补了 8 个基础动作：引体向上、反握引体向上、双杠臂屈伸、器械双杠臂屈伸、哈克深蹲机、俯卧撑、上斜哑铃卧推、杠铃前蹲。
4. 剔除了几个不适合进处方的（哑铃摆动、剪刀腿、半跪髋铰链等）。

**结果**：154 个动作（复合 55、孤立 99），视频 616 个、约 19 MB，放在 `public/exercises/clips/`；数据在 `mock/exercises.json`。

## 6. 已知问题

- V1 动作库里的中文名称和要领来自 MuscleWiki 的翻译，质量参差（例如「杠铃弯举」的要领里写着哑铃）。名称沿用，**要领文案已全部重写**。
- 两个动作的素材文件夹名是 `unknown`（`kickbacks-196`、`dumbbell-bench-wrist-extension-1061`），只是目录名，不影响使用。
- 素材来源是 MuscleWiki，使用依据是用户的声明：作品集展示、非商业用途。每个出现素材的页面保留署名与链接；仓库公开前再确认一次对方当前的条款。
