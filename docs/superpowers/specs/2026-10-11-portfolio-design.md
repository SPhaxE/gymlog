## 1. 视觉体系

- **画布**：1920 × 1080；页边左 120、右 1800；内容区 y 260–980；页脚线 y 1020，页脚「慢牛 Milo · 产品与交互设计」+ 右下 `NN / 22`。
- **颜色**（取自 `design/tokens/tokens.json` 深色原色）：页面底 `gray-0` 暖黑，面 `gray-100 / 150`，文字骨白 `bone-100`，次级 `bone-500`，强调荧光 `lime-*`；浅色只在 P17 用 `paper-*`。荧光可以多处出现，但每页只有一个主焦点。
- **字体**（Figma 内置的 Google Fonts，导入不缺字）：Noto Sans SC（中文）、Barlow Condensed（所有数字和大号英文）、JetBrains Mono（眉题、刻度、时间码、标注编号）。
- **字阶**：12 / 14 / 16 / 18 / 22 / 28 / 40 / 54 / 72；大数字 160 / 240 / 300（Barlow）。
- **页头**：眉题 Mono 14 `NN — 阶段` · 专题名 54 / 800 · 主张句 28 / 700 · 说明 18 / 500。变体：①标准（左上）②压图（P09、P16、P21 小号页头叠在出血大图上）③封面无页头。
- **材质**：颗粒光（主角卡同款）、配重片粒子环、刻度尺、打孔钢板孔阵，都用 App 渲染出的真图层或代码画；不画假界面。
- **标注语言**：细线引线 + Mono 编号（`01`、`02`）+ 一行说明，引线端点是一颗荧光小点。
- **阶段（眉题）**：01–02 总览 · 03–05 定义 · 06–07 结构与视觉 · 08–12 标志性页面 · 13–14 增长 · 15–17 动效与主题 · 18–20 体系与过程 · 21–22 收尾。

## 3. 素材渲染（全部在容器里）

- **App 屏**：`npm run build` + `vite preview`；Playwright 视口 412 × 915、DPR 2.625、深色；注入 `--safe-area-inset-top` / `bottom`（让内容避开 Pixel 8 的挖孔和手势条），截图后叠一条按 Android 14 规格画的状态栏（时间、信号、电池）；场景参数用 `?scenario=plain-prescription` 等现成的。
- **样机**：`back.webp`（机身）+ `mask.webp`（圆角与挖孔）合成；SVG 里机身是一层 PNG、屏幕是另一层 `<image>` + `clipPath`，Figma 里可以单独换屏。
- **方案台 / 组件库 / 规范**：直接截 `/preview`、`/playground`、`/spec` 对应分组。
- **动效帧**：Playwright `clock.install()` → `pause_at` → `run_for` 步进；View Transitions 用 CDP `Animation.setPlaybackRate 0` 冻住再逐帧推进；WebGL（熔流转场）用 SwiftShader 慢慢截，静态帧不受卡顿影响。

## 4. 动效在静态页上怎么讲

四种呈现，按动效的性质选，不只用帧序列：

| 呈现 | 做法 | 用在 |
|---|---|---|
| **刻度帧序列** | 4–6 帧横排，下面一条 Mono 时间刻度（0 / 120 / 240 ms…），与 App 的刻度语言一致 | 导航进度飞入、钢板关灯、曲线钻入 |
| **叠影（长曝光）** | 同一台样机里叠 5–8 帧，越早越淡，一张图看出运动轨迹 | M02 胶囊长成浮层、M03 共享元素展开 |
| **曲线挂帧** | 画出真实的弹簧 / 缓动曲线（Token 参数算），把帧挂在对应时刻的点上，过冲直接看得见 | 心跳颗粒光、弹簧 spring-soft（约 12% 过冲）|
| **切片拼合** | 从点击点向外，一圈取一个时刻的画面拼成一张，晕开的熔流和后面透出的新页面同时可见 | P16 深浅熔流转场 |

再加一个二维码到线上 `/demo`，可以看实时效果，不依赖录屏。

## 7. 制作与交付

- 仓库 `portfolio/`：
  - `lib/pf.py`：颜色、字阶、页头、样机、标注、帧序列 / 叠影 / 曲线挂帧 / 切片拼合、页脚；
  - `shoot/`：渲染 App 屏、方案台、动效帧的 Playwright 脚本；
  - `pages/genNN.py`：每页一个脚本，输出 `out/svg/NN_专题名.svg`；
  - `render.py`：SVG → PNG 预览、合并 PDF；
  - `check.py`：XML 可解析、以 `</svg>` 结尾、字阶白名单、越界、数字白名单。
- **Figma 兼容**：文字是真 `<text>`（不转曲）；不用 `foreignObject`、CSS、滤镜（光晕、模糊、颗粒都先烘进 PNG 图层）；裁切只用 `clipPath`；每页单张 SVG 控制在约 15 MB 内（位图 2 倍、JPEG 能用就用）。
- **流程**：先做 P01、P09、P21 三张定调页给用户看 → 定调后按页序做 → 每页自检（`check.py` + 看 PNG）→ 推 `main`。
- 交付：`portfolio/out/svg/*.svg`（22 张）、`portfolio/out/Milo-作品集.pdf`、`portfolio/out/png/` 预览。

## 8. 风险

- 无头浏览器没有 GPU：动效帧靠冻结时钟逐帧截，慢但可行（handoff §6 已踩过）。
- Pixel 8 挖孔在顶部正中：截图必须注入安全区，否则会压到页头分段控件（试贴已确认）。
- Figma 导入大号内嵌位图可能慢；必要时把背景位图拆成外链文件另附。
