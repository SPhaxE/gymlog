# 返工（g8，2026-10-06 验收后）：页头首屏 + 摘要 + 曲线对齐

用户验收：页头没有设计感、摘要卡的数字看不懂、下滑页头贴顶很难看、每行小曲线纵向对不齐。Stitch g8 出了 4 种页头（`stitch-g8.md`，截图 `screenshots/hifi/gains/g8-*.png`）。

| 方案 | 取 | 舍 |
|---|---|---|
| A 配重片背景 + 一句话 | 淡同心纹做页头背景；「近 4 周练了 15 个动作」一句话；「N 次破纪录」压缩大数字 + 刻度线 | 编造的英文小字（SUPERCOMPENSATION、PROGRESSIVE OVERLOAD）；顶栏品牌行 |
| B 刻度尺三段 | 每条曲线下一道淡基线，列对没对齐一眼看得出；「下次 … × 6」带单位 | 尺子上叠字太挤，且与下面一行图例重复 |
| C 大数字 + 色带 | 组头整行色带（「该加重」荧光，其余灰）；「下次」是每行最大的数字 | 巨大出血的「26」；荧光用在曲线和数值上（违反「每屏一处荧光」） |
| D 环形分段 | **配重片环**：按涨 / 持平 / 退 / 刚开始记分段，环心是练过的动作数；右边图例每项「N 个…」 | 百分比（多一层要解释的数）；整块卡片底（页头不做卡片） |

另外三点不来自 Stitch，来自对验收意见的判断：
- **数字看不懂** → 每个数后面都写单位或名词（个动作 / 次破纪录）；原来的每周柱图去掉（没有坐标，读不出含义），周趋势留给曲线页的时间轴。
- **页头贴顶** → 整页一个滚动区，页头首屏跟着滑走；只有部位筛选一行滑到顶后贴住（半透明虚化底）。
- **曲线对不齐** → 曲线和数值各占固定宽度的列（之前数值列宽随「100.3」「31.4」变，曲线被推着走）；PR 标去掉星形，名称不再折行，行高一致。
