# 6c 记录页 · 钢板打孔日历 + 页头收缩（具体方案，待用户确认）

> 2026-10-06。用户已定：页头选 **C（大标题收成细标题栏）**；日历用 Stitch C 的点阵，做成「钢板打孔」：钢板后面透出荧光绿，练过的日子是大过孔（有光透过），没练的只有一个淡标记；钢板与光影随页面滑动出现真实变化；代码尽量简单、不占内存；设计四种钢印随机出现。
> 原型（一次性，不进 App）：`design/hifi/log/proto/plate.html`（用演示里真实的练过日子画的）；生成脚本 `make_plate_proto.py`。

## 1. 钢板日历长什么样
- 一整块暗色拉丝钢板，四角有铆钉，边缘有倒角高光；月份（8月 9月 10月）是刻在板上的小字。
- **练过的日子 = 冲出来的大过孔**：孔有倒角边、孔壁有暗的一道月牙（看得出板有厚度），**板后面的荧光绿光从孔里透出来**。
- **没练的日子 = 只有一个很淡的小凹点**（样冲眼），没有光。今天 = 板上刻一圈细环（练了就是孔外面套一圈）。还没到的日子更淡。
- 荧光绿只出现在孔里 → 这一页唯一的荧光就是这块钢板（列表里的 PR 标用骨白，不用荧光）。

## 2. 随页面滑动的真实变化（三处，全部是同一件事：光、板、人的相对位置在变）
1. **灯在板后面慢慢平移**：往下滑时板后的光带从一侧移到另一侧，哪几个孔最亮在变，灯移开的孔暗下去、灯移来的孔亮起来。
2. **钢板表面的高光斜着扫过**：像拿着手机转动，板面反光的一道亮带从左扫到右（只照在钢上，不照进孔里）。
3. **钢印的浮雕亮边左右微移**：同一枚印，亮边和暗边的偏移随滑动变化，像光源角度在变。
   另：板滑进屏幕时，钢印有一下「压下去」的缩放（同样随滑动进度走，不是定时动画）。

## 3. 怎么做才简单、不占内存
- **整块日历就是一张 SVG**（约 300 个矢量小元素）：钢板是一块矩形，上面用「遮罩」挖出孔；孔、凹点、铆钉都是复用同一个小图形。没有图片、没有画布（canvas）、没有 WebGL、没有模糊滤镜、没有 backdrop-filter。
- **滑动效果不用脚本**：用浏览器自带的「滚动驱动动画」，纯 CSS（`animation-timeline`），在合成线程里算，主线程不跑每帧代码。浏览器不支持（旧 Safari / Firefox）就保持静态，样子仍然完整。「减少动态效果」设置下也是静态。
- 实测原型：整块钢板 313 个矢量元素，整个原型页面脚本堆内存约 1.4 MB（含整页，其中钢板的部分几十 KB 量级）；对比：现在的点阵日历是 91 个单独的 DOM 小点。
- 代码量预估：钢板组件约 120 行 TSX + 40 行 CSS，不加依赖；数据直接用已有的 `dotMonths`。
- 无障碍：整块钢板对读屏是一张图（「近 3 个月练了 N 天」），列表另有文字；不做逐个孔的点击（命中区 < 48，和现在的点阵日历一样只是展示）。

## 4. 四种钢印（随机出现）
- **位置**：钢板右边「还没到的日子」那块空位（右下），不遮挡有数据的孔。
- **怎么随机**：每次进记录页，从四枚里抽一枚，再随机轻微倾斜（−10°～+10°，像真的压印）；同一次打开期间不变，不连续两次相同。
- **四枚**（都是 Milo 世界里的东西，AIGC 出黑白剪影，我转成矢量路径，每枚约 1–3 KB，页面里只放被抽中的那一枚）：
  1. **牛头印**：Milo 的牛头，几何化、对称、有力。
  2. **扛牛犊印**：米洛每天扛起小牛犊的古希腊剪影（渐进超负荷的由来）。
  3. **配重片印**：配重片俯视，同心环 + 一圈刻度 + 中心孔 + 一个朝上的小缺口。
  4. **递增阶梯印**：三级往上的台阶 + 朝上箭头（「下次多一点」）。
- **浮雕怎么做**：同一枚印画两份——一份亮边、一份暗边，错开 1 像素，中间是钢的颜色；不用位图。
