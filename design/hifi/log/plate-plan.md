## 1. 钢板长什么样
- **板**：深色哑光冲压钢板——糙：细划痕、颗粒、几块脏污、四周压暗；一圈厚实的暗边框（槽 + 发丝亮边），圆角；没有铆钉、没有拉丝抛光感。月份「8月 9月 10月」是板上蚀刻的小字（刻的：亮边在右下）。
- **练过的日子 = 冲出来的孔**（孔径约 0.36 格距 ≈ 13 像素）：规则的圆，没有倒角、台阶、翻边。孔有厚度：露出的亮窗向右下偏一点，所以左上的暗壁厚、右下的薄，四周都能看到一圈壁；冲切面右下一小段碎亮（光从左上来，孔是凹的）；孔口外一圈很浅的暗晕（凹痕）。背光从孔里透出来。
- **没练的日子 = 一个很淡的样冲点**（小凹点：左上暗、右下一丝亮），没有光；今天 = 刻一圈细环（练了就是孔外面套一圈）；还没到的日子更淡的小点。
- 荧光只出现在**孔里和板两侧的漏光里**——这一页唯一的荧光就是这块板（列表里的 PR 标用骨白）。
- 孔不编码数据（不是「练得多孔更大」）；亮暗只是光影：最暗的孔仍有底光（≈ 11% 荧光，是暗绿色不是黑洞），读数据靠孔的有无和下面的列表。

## 2. 随页面滑动的变化（全部合成线程的 CSS 滚动驱动动画，没有主线程每帧代码）
对应 `refs/plate-ref-triptych.jpg` 的左 / 中 / 右三张：**静止 = 右边那张**，往下滑，亮区从右移到中间、再到左边。
1. **一大团软光**（板后面一层）：亮区偏右偏下，往左上渐暗；随滚动平移，**光心比光晕移得快一点**（有景深）。
2. **板两侧的漏光**：亮区靠哪边，哪边的板外缘漏出一圈荧光；右边随滚动熄、左边随滚动亮。
3. **钢面一道很淡的竖向反光**缓慢扫过（`soft-light`，只照在钢上）。
- 行程：滚动 0 → 200（≈ 板顶离屏幕顶的距离；落地时用 Token，如 `calc(var(--milo-size-hit-min) * 4)`）。
- 不支持滚动驱动动画的浏览器（旧 Safari / Firefox）和「减少动态效果」：全部静态定在静止位置，样子完整。

## 3. 做法（简单、不占内存）
- 整块日历 = **一张静态内联 SVG**（钢板 + 遮罩挖孔 + 孔口细节 + 刻字 + 划痕）**+ 板后面几层灯箱 div**（软光、光心、左右漏光、反光带；底光是静态背景）。每个孔 2 个节点（遮罩里的一个圆 + 一个孔口细节 `<use>`），整块板 < 400 个节点；没有图片 / canvas / WebGL / 噪声滤镜 / 模糊滤镜。
- **坑（已踩）**：`animation-timeline: scroll(nearest)` 绑的是「最近的滚动容器」，而 `overflow: hidden` 的元素本身就是滚动容器——`.plate` 用了 `overflow: hidden` 时，灯箱层的时间线绑到它身上，进度永远是 0，光不动（只有挂在它外面的漏光在动）。**圆角裁切一律用 `overflow: clip`**。
- 颜色全部来自 Token（`--milo-prim-gray-*`、`lime-500 / 300 / 900`），透明度用 `color-mix(in srgb, … N%, transparent)`；落地进 `src/` 要过 `check:hardcoded`（禁十六进制、`rgb()`、`\d+px`、`\d+ms`），原型里的 `fill="#000"` 之类（遮罩里的黑白）要换成 Token 色或 `black / white` 关键字。
- 数据复用 `dotMonths(trained, now, 3)`（`src/components/dataviz.tsx`）；今天练过时现在会被「今天」盖掉，落地时给格子补一个「当天练过」标记。读屏：整块板是一张图「近 3 个月练了 N 天」，下面列表有文字；孔不单独点击（< 48 命中区，和现有点阵一样只展示）。
- 光强：`--k`（0.6 弱 / 1 中 / 1.45 强），默认「中」。
