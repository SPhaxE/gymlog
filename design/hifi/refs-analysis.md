# Nano Banana 参考图分析 → 视觉语言 v2

> 2026-10-03。来源：用户用提示词包 v1/v2 生成的 54 张参考图，归档在 `design/hifi/<页面>/refs/nb-<页面>-<方向><序号>.jpg`（不进网页包和 APK）。
> 元素提取板：`screenshots/hifi/refs-elements.png`（`python3 design/hifi/refs_board.py`）。
> 身体页 Stitch 第 1 轮的结论（B 克制精致的层级 + D 的胶囊质感）一并并入。

## 结论

三个方向里，**C（张力）的数字 + A（配重片）的刻度与纹理 + B（克制）的层级**最好，而且三者能合在一起：用暖黑底，配骨白和荧光两个色，数字用压缩粗体，刻度线当量尺。这套就是「视觉语言 v2」。它不推翻阶段 3 选的方向 B「配重片」，而是在其基础上补了两个参考图反复出现、我们规范里没有的东西：**骨白色**和**压缩粗体数字**。

## 采用的 10 个元素

| # | 元素 | 规则 | 例图 |
|---|---|---|---|
| 1 | **暖黑 + 骨白 + 荧光** | 骨白（暖米白，约 `#E9E3D3`）用于「选中 / 实心」：导航选中项、分段控件选中、档案格子、「完成」这类中性主按钮。荧光仍然每屏只给一个焦点。 | body-C1、me-B1、summary-B1 |
| 2 | **压缩粗体数字** | 关键读数（重量、组数、PR 数、恢复 %）用高瘦的展示型数字（Barlow Condensed / Oswald 一类，V1 用的是 Bebas Neue）；单位和中文用黑体小字。 | body-C1、gains-C1、summary-C2 |
| 3 | **刻度** | KPI 下的细刻度线、行间的刻度尺、容量刻度尺（最低 / 适宜 / 上限）。用作分隔线和量尺，不做装饰。 | body-A3、home-A3、sheet-A2 |
| 4 | **配重片同心纹** | 同心车削纹或刻度盘做英雄区背景：结算页、增量页页头。每页最多一处，透明度很低。 | gains-A1、summary-A2 |
| 5 | **胶囊** | 焦点胶囊用实心荧光底 + 黑字；静止胶囊是「名称 · 数值 · 细条」；有组数的胶囊底色按比例填充骨白暗调，胶囊本身就是量尺；0 组用斜纹。 | body-B1、body-C1 |
| 6 | **引擎结论色带** | 增量页「该加重」组头用荧光色带，「保持」「该减重」用灰色带 + 箭头形状（↑ = ↓）。 | gains-B1、gains-C1 |
| 7 | **导航：5 项都带名称** | 参考图全都给 5 项加了名称，360 dp 下放得下，也比只有图标好认。选中项是骨白实心圆底 + 黑图标；外圈荧光细环表示今日进度。休息时，选中项的名称换成剩余时间。 | gains-C2、log-C2、body-B1 |
| 8 | **结算的庆祝** | 「4 项 PR」压在一条荧光斜带上，这是全 App 唯一允许「大声」的一屏；逐动作的 PR 用形状 + 文字标出。 | summary-C1、summary-A1 |
| 9 | **训练页** | 休息条在顶部，配荧光倒计时细线；当前行高亮并显示光标；键盘右列是 −2.5 / +2.5 / 确认，单手可达。 | session-B1、session-C2 |
| 10 | **详情面板** | 四段时相做成分段控件，当前段用荧光；容量用刻度尺标出三条地标。 | sheet-B1 |

## 不采用的

- **AI 画的人体**：解剖细节和全身构图都不用。人体只用 MuscleWiki 真实路径，只露半边。
- **编造的英文标签**：例如「NEXT TARGET」「LEFT / RIGHT」「OVERLOAD ENG.」。
- **满屏的出血巨型数字**：只留给结算页，其他页面不用。
- **荧光大面积铺色或发光**：例如 C 方向把人体背景整片染成荧光，与「每屏一处荧光」冲突。
